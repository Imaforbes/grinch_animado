> **The Grinch (El Grinch)** is a creative, responsive Christmas character animation crafted entirely from scratch using pure **HTML5**, advanced **CSS3 Keyframe Animations**, an interactive **3-Size Holiday Heart** mechanism, and an atmospheric **Winter Snowfall Engine**.

### 👉 [CLICK HERE TO VIEW THE LIVE ANIMATION DEMO](https://imaforbes.github.io/grinch_animado/)

---

## ✨ Interactive Features (Phase 1 & 2)

### ❤️ 1. *"His Heart Grew 3 Sizes!"* (Interactive Heart)
Inspired by the iconic Grinch story, users can interact with the character directly:
* **Interactive Glowing Heart:** Click directly on the Grinch's red chest heart or use the Hallmark editorial control bar (`❤️ HACER CRECER CORAZÓN [1x]`).
* **3-Stage Size Progression:**
  * **`1x` (Default):** Grinch Malhumorado *(Grumpy Grinch)* — subtle heartbeat pulse.
  * **`2x` (Click 1):** Sintiéndo... Sentimientos *(Feeling Feelings)* — vibrant `#00F0FF` telemetry aura.
  * **`3x` (Click 2):** ¡Espíritu Navideño al 100%! *(100% Christmas Spirit)* — fast heartbeat animation and radiant holiday glow.

### ❄️ 2. Winter Snowfall Engine & Control (Phase 2)
* **CSS3 Keyframe Snowfall:** 30 lightweight, randomized snowflakes (`❄`) falling smoothly across the seasonal winter sea-blue background with natural depth, opacity variations, and horizontal swaying.
* **Editorial Snow Toggle:** A dedicated control button (`❄️ NIEVE INVERNAL [ON / OFF]`) allowing visitors to toggle the snowfall background atmosphere instantly.

## 🎨 Visual & Technical Design

* **Winter Maritime Palette:** Seasonal sea-blue `#3351d8` viewport background contrasted with a slate `#869fa7` character container, making the Grinch's signature lime-green (`#86c92c`) and Santa red (`#FF4742`) colors pop vividly.
* **Fluid Keyframe Choreography:** Synchronized animations for hat shaking, eye/pupil tracking, nose movement, heartbeat pulsing, and atmospheric snowfall.
* **Expressive Typography:** Utilizes the Google Font `'Rock Salt'` for an authentic, playful holiday title.

---

## 🛠️ Keyframe Animations

1. **`snowfall` & `sway`**: Continuous atmospheric descent and horizontal oscillation for background snowflakes.
2. **`heartbeat` & `heartbeat-fast`**: Organic pulsing animation for the Grinch's glowing heart across all 3 sizes.
3. **`shake` & `shake-white-ball`**: Dynamic oscillating rotation for the Santa hat tip and white pom-pom.
4. **`move-eyes` & `move-pupil`**: Periodic lateral tracking movement simulating character awareness.
5. **`move-nose`**: Subtle rotational twitching for facial expression.
6. **`redAndGreen-shadow` & `white-shadow`**: Smooth inset box-shadow shifts that create a 3D ambient lighting effect.

## 🚀 How to Run Locally

No installation, build steps, or servers required:
1. Clone the repository:
   ```bash
   git clone https://github.com/Imaforbes/grinch_animado.git
   cd grinch_animado
   ```
2. Open **`index.html`** in any modern web browser (Chrome, Firefox, Safari, Edge).
